One language, three grammars

Bare Grammar (Keenan & Stabler 2003) treats a grammar as data: categories, a lexicon and rules. Implemented in Lean 4, the same language states a linear grammar, X-bar theory with GB modules, and the workspace-era Minimalist Program. What is running

The language is BareSyntax/Basic.lean: an expression is a pair ⟨string, category⟩, a rule is a partial function on expressions, and an expression is in the language when a derivation of it exists (Deriv, CanYield). It is the base of the syntax-game project, with one addition: besides rules whose domain is a list of categories, rules whose domain is a decidable condition. Level 3 needs these, because there a category is a whole workspace.

The states and messages on this page were produced by running Lean 4.23.0 on syntax-game-v2-demo at commit cfc7de0. To step through the same proofs yourself, open playground/ in VS Code; it needs no game server.
