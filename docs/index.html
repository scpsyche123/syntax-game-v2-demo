One language, many grammars

Bare Grammar (Keenan & Stabler 2003) treats a grammar as data: categories, a lexicon and rules. In this Lean 4 implementation the same language states a linear grammar, X-bar theory with GB modules, and the workspace-era Minimalist Program. Each level below is playable: pick inputs, pick a rule, and the grammar accepts or rejects the step.

This is a five-level demo that shows the basic capabilities of the system. The full game has not been built yet. If you would rather not play every step yourself, click Solution to see the result.

What is running

The language is BareSyntax/Basic.lean in syntax-game-v2-demo: an expression is a pair ⟨string, category⟩, a rule is a partial function on expressions, and an expression belongs to the language when a derivation of it exists. Rules come in two forms: with a domain given as a list of categories (the linear levels), and with a domain given by a pattern and a decidable condition (the X-bar schema, where X and Y are variables, and MERGE, where a category is a whole workspace).
